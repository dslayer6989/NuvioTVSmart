# Live TV theme fonts

Heading and label faces for the Live TV themes (same files as the Nuvio Live TV desktop and Android builds). All are distributed under the SIL Open Font License 1.1; each font's license is next to it.

- `theme_silkscreen_*.ttf`: Silkscreen (Teletext). See `silkscreen-OFL.txt`.
- `theme_vt323_regular.ttf`: VT323 (CRT Phosphor). See `vt323-OFL.txt`.
- `theme_audiowide_regular.ttf`: Audiowide (Synthwave Sunset). See `audiowide-OFL.txt`.
- `theme_oswald_variable.ttf`: Oswald (Game Day). See `oswald-OFL.txt`.
- `theme_limelight_regular.ttf`: Limelight (Drive-In Marquee). See `limelight-OFL.txt`.
- `theme_quicksand_variable.ttf`: Quicksand (Aurora). See `quicksand-OFL.txt`.
